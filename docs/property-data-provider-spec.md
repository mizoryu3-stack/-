# 物件データ提供フォーマットのお願い（民泊物件サーチ）

このドキュメントは、「民泊物件サーチ」アプリへ物件データをご提供いただく際の、項目・形式のご案内です。

## 提供方法

- **Excel／CSV／Googleスプレッドシート**のいずれでも構いません（Googleスプレッドシートの場合はCSV形式でダウンロードして共有いただく形で問題ありません）。
- 1ファイル＝現在掲載中の物件を**まとめて全件**、で構いません。差分だけを抽出していただく必要はありません（新着・更新・掲載終了の判定はこちら側で自動的に行います）。
- 頻度は月次を想定していますが、変更があれば都度いただいても構いません。
- **1行目は見出し行**とし、下表の「列見出し」欄の文言をそのままお使いください（順序は自由です）。文言が異なる場合も、お預かりした後にこちらで調整可能です。

## 大切なお願い

- 「民泊利用が**法的に可能**」と断定する表現ではなく、あくまで**「民泊利用についてオーナー様・貴社に確認できている状況」**としてご記入ください（下記「民泊相談可否」欄）。
- 物件IDや物件URL等、**同じ物件を毎回同じ値で識別できる項目**をできるだけ含めてください。これが無いと、同じ物件を再送していただいた際に重複登録されてしまう可能性があります。

### 「民泊相談可否」欄について

以下の4つのいずれかでご記入ください（表記ゆれは吸収しますが、できるだけこのままの表現でお願いします）。

| 記入内容 | 意味 |
|---|---|
| オーナー確認済み・相談可能 | オーナー様に確認済みで、民泊利用について相談可能 |
| オーナー確認が必要 | 民泊利用についてオーナー様への確認が必要 |
| 民泊不可 | 民泊利用は不可 |
| 未確認 | 現時点で未確認（空欄でも同じ扱いになります） |

※「民泊可能」という法的な断定ではなく、あくまで確認状況としてお願いします。

## ご提供後の流れ

1. いただいたファイルを、こちらのアプリの管理画面から取り込みます。
2. 取り込み時、数値・必須項目に不備がある行はエラーとして表示され、正常な行のみ反映されます（不備があった行は個別にご相談させてください）。
3. 毎月同じ形式で再送いただければ、新しく増えた物件・家賃変更・掲載終了を自動的に反映します。
4. 民泊相談可否や条件に合う新着物件は、保存済みの検索条件に応じて自動的に通知されます。

ご不明点があれば、随時ご相談ください。
