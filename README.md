# 筋トレ記録

ブラウザだけで完結する筋トレ記録アプリです。サーバーは不要です。

## 主な機能

- **基本の記録**: 日付・種目・重量・回数・セット数を記録 (重量・回数は5刻みのステッパーで素早く入力)
- **トレーニング種別 (上半身/下半身/全身)**: 選択すると、実際に記録した種目の部位と照らし合わせて毎回自動で評価コメントを表示
- **種目ごとの履歴・進捗グラフ**: 最大重量 / 総ボリュームの推移、初回からの伸びを表示
- **体重の推移グラフ**: 記録時に体重を入力すると、その推移を確認可能
- **セッションごとの振り返り**
  - 前回との総ボリューム比較
  - 種目ごとに毎回、具体的なアドバイスを生成(例:「同じ重量が続いているので+2.5kgに」「あと1セット追加できそう」など)
  - 消費カロリーの概算(METs法。体重・トレーニング時間が未入力の場合は仮の値で概算し、その旨を表示)

## セットアップ

```bash
npm install
npm run dev              # 開発サーバー
npm run build            # 本番ビルド (dist/ に出力、そのまま静的ホスティング可能)
npm run build:artifact   # dist/ を1枚のHTML (artifact.html) にまとめる (claude.ai Artifact用)
npm run preview          # ビルド結果をローカルで確認
```

## データの保存について

- **claude.ai の Artifact として開いている場合**: 記録はこのページ自体 (Artifactの公開データ) に保存されます。ブラウザのデータを消してもコードが更新されても消えず、同じURLであれば別のブラウザ・端末からでも同じ記録が見られます。ヘッダーに保存状態(「✓ 記録はこのページ自体に保存されます」/「この端末のブラウザにのみ保存されています」)が表示されます。
- **それ以外の静的ホスティング (GitHub Pagesなど) で開いている場合**: ブラウザの `localStorage` にのみ保存されます。サーバーには送信されません。
- ブラウザのlocalStorageに既存の記録がある状態でArtifact永続化が使えるようになった場合、初回に一度だけ自動でArtifact側へ移行(publish)されます。
