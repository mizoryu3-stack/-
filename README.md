# 筋トレ記録

ブラウザだけで完結する筋トレ記録アプリです。サーバーは不要で、記録はブラウザの `localStorage` に保存されます。

## 主な機能

- **基本の記録**: 日付・種目・重量・回数・セット数を記録
- **種目ごとの履歴・進捗グラフ**: 最大重量 / 総ボリュームの推移を折れ線グラフで確認
- **セッションごとの振り返り**
  - 前回との総ボリューム比較
  - 種目別の前回比(重量・ボリューム)
  - 次回への改善提案(重量が停滞している種目の指摘、部位バランスのアドバイスなど)
  - 消費カロリーの概算(METs法。体重・トレーニング時間が未入力の場合は仮の値で概算し、その旨を表示)

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド (dist/ に出力)
npm run preview  # ビルド結果をローカルで確認
```

## データについて

記録はすべてブラウザの `localStorage` に保存されます。サーバーには送信されません。ブラウザのデータを消去したり、別のブラウザ・端末からアクセスすると記録は共有されない点にご注意ください。
